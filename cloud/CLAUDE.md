# harness
- The `## harness` block at the top of context is persistent memory for this user and repo. Treat it as true unless the code in front of you contradicts it.
- When you learn a decision, a constraint, or a gotcha that a future session would otherwise rediscover, run `harness remember "<one-sentence fact>"`. Add `--global` only for facts that apply in every repo.
- A line starting `Remember:` at the end of your message is stored automatically when the turn ends.
- Never write secrets, tokens, private hostnames, or personal data to memory.
- If the block says `(cached ...)`, the memory provider was slow or unreachable; the facts are still valid, just possibly stale.
